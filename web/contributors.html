Details How contributions and missing fields are counted

Totals are unavailable until the public contributions load.

Published contributions
Successful publications still public, counted once each. Retrying a save adds nothing. A contribution can add a place, edit it, add a note or undo a change.
Places added / Edits / Notes
Distinct places added through public contributions / individual edit publications, regardless of how many fields changed / separate note publications. These are activity counts, not a measure of quality.
Undo and earlier releases
Undo is counted separately. Earlier verified releases are listed separately when their activity type cannot be established. Imported and base inventory places are excluded from contribution totals. Withdrawn work is excluded.
Public attribution
Only usernames chosen for public credit appear. Matching names can belong to different contributors; different usernames are not linked. Directory identities last for this response only. Work without verified attribution stays unattributed.
Missing / Unknown
Missing means core place or source details are empty. Unknown means information is unresolved or recorded as unknown. Neither is a judgment about the contributor.
Optional / Not applicable
Blank descriptions on existing places and other optional details are not gaps. Image details are not applicable when there is no image. Present means a value exists, not that it has been independently verified.
